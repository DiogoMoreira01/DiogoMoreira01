## 🏗️ Projeto em destaque

### Vitare

Plataforma para personal trainers acompanharem a evolução física de seus alunos.

#### Objetivo

Permitir que treinadores gerenciem seus alunos, acompanhem resultados, centralizem informações e reduzam a perda de clientes.

#### Stack

- Flutter
- FastAPI
- PostgreSQL
- Firebase
- Docker
